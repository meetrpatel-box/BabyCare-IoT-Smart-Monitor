# 📱 Android Application APK Downloads

This folder contains information about the BabyTrack Android mobile app APK.

### Direct Download & Installation

The latest optimized APK can be downloaded from:
- **GitHub Releases**: [Latest Release](../../releases/latest)
- Or directly install from the release asset.

### System Requirements
- **OS**: Android 8.0 (Oreo) or higher (Android 8 - 15)
- **Architecture**: ARM64-v8a (standard on all modern Android devices)
- **Permissions**:
  - Microphone (for 2-way talkback)
  - Network / Wi-Fi (for local LAN direct streaming & Cloud WebRTC)
