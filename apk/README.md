## 📋 Installation Instructions
1. Download `babycare-app-v1.0.0-arm64.apk` to your Android device.
2. Tap the downloaded file in your file manager / notification tray.
3. If prompted, allow "Install Unknown Apps" for your browser / file manager.
4. Open the app, grant **Microphone** and **Local Network** permissions.
5. Enter your baby monitor's local IP or connect via Cloud Relay!
