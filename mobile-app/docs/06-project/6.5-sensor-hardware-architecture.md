## Part 1: Breath Rate Monitoring

### 1.1 Problem Statement

**Parent Anxiety Level**: 🔴 Critical  
**Peak Concern Period**: 0-6 months  
**Market Gap**: Only Nanit (camera-based) and Miku (radar) offer this

**Parent Questions We Answer**:
- "Is my baby breathing?"
- "Is baby's breathing normal for their age?"
- "Should I be worried about this breathing pattern?"

### 1.2 Data Model

```dart
// lib/models/breathing_model.dart
class BreathingModel {
  final String id;
  final String babyId;
  final DateTime timestamp;
  
  // Core metrics
  final int breathsPerMinute;        // Normal: 30-60 (newborn), 20-40 (1yr)
  final double? breathDepth;         // Shallow vs deep
  final bool isIrregular;           
  
  // Derived status
  final BreathingStatus status;      
  final int secondsSinceLastBreath;  // Critical safety metric
  
  // Context
  final String? sleepState;          
  final double? bodyTemperature;     
  
  final DateTime createdAt;
}

enum BreathingStatus {
  normal,
  fast,
  slow,
  irregular,
  paused,         // ⚠️ ALERT CONDITION
  noReading,
}
```

### 1.3 Age-Based Normal Ranges

| Age | Normal BPM | Warning | Alert |
|-----|------------|---------|-------|
| 0-3 months | 30-60 | <25 or >70 | <20 or >80 |
| 3-6 months | 25-45 | <20 or >55 | <15 or >65 |
| 6-12 months | 20-40 | <15 or >50 | <12 or >60 |

### 1.4 Alert Thresholds

| Alert Level | Condition | Action |
|-------------|-----------|--------|
| 🟢 Normal | BPM within age range | Dashboard display |
| 🟡 Warning | BPM 10% outside range | Log + subtle indicator |
| 🟠 Elevated | BPM 20% outside OR irregular 5+ min | Push notification |
| 🔴 Critical | **No breath 15+ seconds** | LOUD ALARM + vibration |

### 1.5 Implementation Priority: **P0**

## Part 2: Cry Detection & Classification

### 2.1 Problem Statement

**Parent Anxiety Level**: 🔴 Critical  
**Peak Concern Period**: 0-3 months (colic period)  
**Market Gap**: No competitor does WHY baby is crying

**Parent Questions We Answer**:
- "Why is my baby crying?"
- "Is this a hungry cry or tired cry?"
- "How often is baby crying at night?"

### 2.2 Cry Classification Types

Based on Dunstan Baby Language research:

| Cry Type | Sound Pattern | Physical Cues | Parent Action |
|----------|---------------|---------------|---------------|
| **Hungry** | "Neh" sound, rhythmic | Rooting, sucking | Feed baby |
| **Tired** | "Owh" sound, yawning tone | Eye rubbing | Put to sleep |
| **Discomfort** | "Heh" sound, lower pitch | Arching back | Check diaper/temp |
| **Pain** | High-pitched, sudden | Stiff body | Check for cause |
| **Gassy** | "Eairh" sound, grunting | Legs drawn up | Burp/gas relief |
| **Overstimulated** | Building intensity | Turning away | Reduce stimulation |
| **Lonely** | Stops when picked up | Arms reaching | Comfort/hold |
| **Colic** | Inconsolable, 3+ hours | Nothing helps | Contact doctor |

### 2.3 Data Model

```dart
// lib/models/cry_event_model.dart
class CryEventModel {
  final String id;
  final String babyId;
  final DateTime startTime;
  final DateTime? endTime;
  final Duration? duration;
  
  // ML classification
  final CryType classifiedType;
  final double confidence;
  final CryType? parentCorrectedType;
  
  // Audio characteristics
  final double avgIntensity;
  final double peakIntensity;
  final double avgPitch;
  final CryPattern pattern;
  
  // Context
  final CryContext context;
  
  // Resolution
  final ResolutionAction? resolvedBy;
  final DateTime? resolvedAt;
  final String? notes;
  
  final DateTime createdAt;
}

enum CryType {
  hungry,
  tired,
  discomfort,
  pain,
  overstimulated,
  gassy,
  lonely,
  colic,
  unknown,
}

enum CryPattern {
  rhythmic,
  building,
  sudden,
  irregular,
  fluctuating,
}

class CryContext {
  final Duration timeSinceLastFeed;
  final Duration timeAwake;
  final Duration timeSinceLastDiaperChange;
  final double currentTemperature;
  final bool isWithinColickHours;  // 5pm-11pm
}
```

### 2.4 ML Pipeline

```
Audio Capture → Feature Extraction → Cry Detection → Cry Classification
                      │                    │                  │
                    MFCC              Binary Model      Multi-class Model
                 Spectral              cry/not         hungry/tired/etc.
                 Pitch/Hz               (on-device)       (cloud)
```

### 2.5 Context-Enhanced Predictions

Combine ML output with baby context:

| ML Says | Context | Enhanced Prediction |
|---------|---------|---------------------|
| "tired" | Awake 2+ hours | ✅ "Likely tired - put to sleep" |
| "hungry" | Fed 15 min ago | 🤔 "Might be gassy, try burping" |
| "unknown" | 6pm + 2-4 month old | "Possible colic/witching hour" |

### 3.3 Position Detection (SIDS Prevention)

**Why Critical**: AAP recommends back sleeping. Rolling to stomach increases SIDS risk.

```dart
// lib/models/position_detection_model.dart
class PositionDetectionModel {
  final String id;
  final String babyId;
  final DateTime timestamp;
  
  final BabyPosition position;
  final double confidence;
  final bool isAlert;
  
  final String? screenshotUrl;
  
  final DateTime createdAt;
}

enum BabyPosition {
  back,       // ✅ Safe
  side,       // ⚠️ Warning
  stomach,    // 🔴 Alert (<6 months)
  sitting,
  moving,
  unknown,
}
```

**Alert Logic**:
```dart
if (baby.ageInMonths < 6 && position == BabyPosition.stomach) {
  // Critical alert with screenshot
  alertService.sendCriticalAlert(
    title: "⚠️ Baby Rolled to Stomach",
    message: "${baby.name} rolled onto stomach. Check on baby.",
    screenshot: capturedScreenshot,
  );
}
```
