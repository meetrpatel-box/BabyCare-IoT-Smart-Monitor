### Feature Gating Summary

**Free Tier**:
- Manual tracking (feeding, diaper, sleep, medication, growth, vaccine)
- Basic milestones (manual logging, 1 photo per)
- 100 photos max, 500 MB storage
- 5 albums max
- Basic timeline view

**Premium Tier**:
- All manual tracking features
- AI photo tagging & facial recognition
- Unlimited photos/albums, 10 GB storage
- Milestone celebrations & CDC percentiles
- Smart albums & advanced search
- Memory book PDF export

**Premium + AnvayaPod Device**:
- All Premium features
- Auto-detection from sensor data (sleep, feeding, growth milestones)
- ESP32-CAM auto-capture
- 60GHz mmWave vital signs monitoring (HR, RR)
- Unlimited videos, 50 GB storage
- Timeline with sensor data integration
