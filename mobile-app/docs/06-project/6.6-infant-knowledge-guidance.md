## Executive Summary

This document defines the architecture for **infant knowledge, guidance, and educational content** within the AnvayaPod ecosystem. Beyond sensor monitoring, parents need **trusted information** to navigate the first year.

**Core Principle**: Be the **single source of truth** for infant care guidance, replacing the need for multiple apps, Google searches, and conflicting advice.

## Part 3: Personalization Engine

### 3.1 Context-Aware Content Delivery

**The Magic**: Content appears when parents need it, based on their baby's data.

```dart
class ContentPersonalizationService {
  // Get relevant content based on baby's current state
  Future<List<ContentItem>> getPersonalizedContent(String babyId) async {
    final baby = await _babyService.getBaby(babyId);
    final vitals = baby.latestVitals;
    final recentEvents = await _eventService.getRecentEvents(babyId);
    
    final content = <ContentItem>[];
    
    // 1. Age-based content
    content.addAll(await _getAgeBasedContent(baby.ageInMonths));
    
    // 2. Milestone reminders
    content.addAll(await _getUpcomingMilestones(baby.ageInMonths));
    
    // 3. Data-triggered content
    if (vitals?.temperature != null && vitals!.temperature! > 37.5) {
      content.add(await _getArticle('fever-management-guide'));
    }
    
    if (baby.ageInMonths == 4) {
      content.add(await _getArticle('4-month-sleep-regression'));
    }
    
    if (recentEvents.hasManyWakeUps) {
      content.addAll(await _getSleepImprovementContent(baby.ageInMonths));
    }
    
    // 4. Time-based content
    if (_isEvening()) {
      content.add(await _getTip('bedtime-routine-reminder'));
    }
    
    // 5. Feeding stage content
    if (baby.ageInMonths >= 4 && baby.ageInMonths <= 6) {
      content.add(await _getArticle('starting-solids-guide'));
    }
    
    return _rankAndDedupe(content);
  }
}
```
