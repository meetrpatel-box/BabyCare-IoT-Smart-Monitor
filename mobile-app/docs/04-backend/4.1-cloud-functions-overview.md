## Executive Summary

BabyTrack Monitor uses Firebase Cloud Functions (Node 20, TypeScript) to power the cry detection ML pipeline, colic pattern analysis, push notifications, consent/GDPR handling, training data export, and admin model management. All functions live in the `functions/` directory at the project root.

## 2. Function Inventory

### Firestore Triggers

| Function | Trigger | Source | Description |
|----------|---------|--------|-------------|
| `onCryAudioUploaded` | `babies/{babyId}/cryEvents/{eventId}` update | `cryClassification.ts` | Fires when `hasAudioFeatures` transitions to `true`. Loads audio features, runs classifier, writes `cloudClassification` back. |
| `onConsentRevoked` | `dataDeleteRequests/{id}` create | `consentHandler.ts` | Deletes audio features + raw audio from Storage. Clears ML fields from event docs. Marks request completed. |
| `onCryEventCreated` | `babies/{babyId}/cryEvents/{eventId}` create | `pushNotifications.ts` | Sends Tier 1 FCM push to all family members: "Baby is crying!" |
| `onCryClassified` | `babies/{babyId}/cryEvents/{eventId}` update | `pushNotifications.ts` | Sends Tier 3 FCM push when `cloudClassification` is newly set with actionable suggestion. |

### Callable Functions

| Function | Auth | Source | Description |
|----------|------|--------|-------------|
| `classifyCry` | Authenticated | `cryClassification.ts` | On-demand classification of a cry event. |
| `exportTrainingData` | Admin | `trainingExport.ts` | Export labeled events as JSONL manifest to Storage. |
| `detectColicPatterns` | Authenticated | `colicPatternDetector.ts` | Analyze colic patterns for a baby (Wessel's criteria). |
| `getModelConfig` | Admin | `adminFunctions.ts` | Read current model configuration. |
| `updateModelConfig` | Admin | `adminFunctions.ts` | Update model backend, version, A/B test config. |
| `getModelPerformance` | Admin | `adminFunctions.ts` | Aggregate accuracy stats across babies. |
| `setAdminClaim` | Admin | `adminFunctions.ts` | Grant/revoke admin custom claim on a user. |

### Scheduled Functions

| Function | Schedule | Source | Description |
|----------|----------|--------|-------------|
| `scheduledColicAnalysis` | Daily 3:00 AM UTC | `colicPatternDetector.ts` | Runs colic analysis for all babies with recent cry events. Updates `latestVitals` if risk is moderate/severe. |

## 4. Setup & Development

### Prerequisites

- Node.js 20+
- Firebase CLI (`npm install -g firebase-tools`)
- Firebase project configured

### Install Dependencies

```bash
cd functions
npm install
```

### Build

```bash
npm run build            # One-time compile
npm run build:watch      # Watch mode
```

### Run Tests

```bash
npm test                 # Run all 75 tests
npm run test:watch       # Watch mode
```

### Local Emulator

```bash
npm run serve            # Build + start Firebase emulator on port 5001
```

### View Logs

```bash
npm run logs             # View deployed function logs
```

---

## 5. Deployment

### Deploy All Functions

```bash
cd functions
npm run deploy
# equivalent to: firebase deploy --only functions
```

### Deploy Specific Function

```bash
firebase deploy --only functions:onCryAudioUploaded
firebase deploy --only functions:detectColicPatterns,functions:scheduledColicAnalysis
```

### Verify Deployment

```bash
firebase functions:list
```

## 6. Environment & Configuration

### Runtime Config

Model configuration is stored in Firestore at `modelConfig/cryClassifier`:

```json
{
  "activeVersion": "heuristic-v1.0",
  "backend": "heuristic",
  "storagePath": null,
  "vertexEndpointId": null,
  "abTest": {
    "challengerVersion": "tfjs-v1.0",
    "challengerBackend": "tfjs",
    "challengerStoragePath": "models/cry-classifier/v1.0/model.json",
    "trafficPercent": 20
  }
}
```

### Admin Access

Admin functions require a custom claim `admin: true` on the Firebase Auth user. Set via:

```bash
# Using Firebase Admin SDK or the setAdminClaim Cloud Function
```
