## 1. Collection Hierarchy

```
babies/{babyId}/
├── cryEvents/{eventId}            → Cry detection events with ML classification
└── colicPatterns/{date}           → Daily colic pattern analysis results

devices/{deviceId}/
└── cryDetections/{detectionId}    → Raw BLE cry detections from device

users/{userId}
└── preferences.cryDataConsent     → User consent level for cry data

modelConfig/cryClassifier           → Active model configuration + A/B test
trainingDatasets/{version}          → ML training export metadata
dataDeleteRequests/{requestId}      → GDPR data deletion requests
adminAuditLog/{logId}              → Admin action audit trail
```

## 2. Cry Events

**Path**: `babies/{babyId}/cryEvents/{eventId}`
**Created by**: Flutter app (via BLE detection or manual), Cloud Functions
**Updated by**: Cloud Functions (classification), Flutter (feedback)

```typescript
interface CryEventDocument {
  // Identity
  babyId: string;
  deviceId: string | null;              // Null for manual entries

  // Timing
  startTime: Timestamp;
  endTime: Timestamp | null;            // Null if ongoing
  durationSeconds: number | null;       // Computed on end
  createdAt: Timestamp;

  // Intensity
  intensity: number | null;             // 0.0–1.0 from device

  // ─── Progressive Classification Pipeline ───

  // Tier 2: Edge (TFLite on device)
  edgeClassification: string | null;    // "hungry", "tired", etc.
  edgeConfidence: number | null;        // 0.0–1.0

  // Tier 3: Cloud (heuristic → YAMNet → Vertex AI)
  cloudClassification: string | null;
  cloudConfidence: number | null;
  classProbabilities: Record<string, number> | null;  // Per-class softmax
  cloudModelVersion: string | null;     // e.g. "heuristic-v1.0"
  cloudProcessingTimeMs: number | null;
  cloudClassifiedAt: Timestamp | null;

  // Best available (shown to user)
  classification: string;               // One of CryType values below
  classificationSource: "edge" | "cloud" | "heuristic" | "parentCorrected";

  // ─── Parent Feedback (Ground Truth) ───

  parentConfirmed: boolean;             // Parent confirmed classification
  parentCorrectedType: string | null;   // Parent's correction (overrides all)
  correctedAt: Timestamp | null;
  resolution: string | null;            // "fed" | "diaperChange" | "rocked" | "held" |
                                        // "pacifier" | "sleep" | "other" | "selfResolved"

  // ─── ML Training Data ───

  hasAudioFeatures: boolean;            // Triggers onCryAudioUploaded
  hasRawAudio: boolean;
  hasKeyFrames: boolean;
  audioFeaturesPath: string | null;     // Storage: features/{eventId}.json
  rawAudioPath: string | null;          // Storage: audio/{eventId}.wav
  keyFramesPaths: string[] | null;      // Storage: frames/{eventId}/
  audioFeatures: Record<string, any> | null;  // Inline for small payloads

  // ─── Consent & Export ───

  dataConsent: "featuresOnly" | "fullAudio" | "none";
  exportedToTraining: boolean;
  trainingDatasetVersion: string | null;

  // ─── Sensor Context ───

  sensorContext: {
    heartRate: number | null;
    breathRate: number | null;
    bodyTemp: number | null;
    envTemp: number | null;
    humidity: number | null;
    movement: number | null;
    roomNoise: number | null;
  } | null;
}
```

### CryType Values

| Value | Description |
|-------|-------------|
| `hungry` | Rhythmic, low-pitched, repetitive |
| `tired` | Whiny, building intensity with yawns |
| `pain` | Sudden, high-pitched, piercing |
| `colic` | Inconsolable, long duration, high intensity |
| `gassy` | Short bursts, straining, pulling legs |
| `discomfort` | Moderate, persistent, not rhythmic |
| `attention` | Fussing, stop-start, low intensity |
| `overstimulated` | Escalating, turning away |
| `unknown` | Cannot classify |

### Ground Truth Priority

```
parentCorrectedType > confirmed cloudClassification > unconfirmed cloudClassification > edgeClassification > heuristic
```

## 3. Colic Patterns

**Path**: `babies/{babyId}/colicPatterns/{date}`
**Created by**: `detectColicPatterns` (callable) or `scheduledColicAnalysis` (scheduled)
**Key**: Date is `YYYY-MM-DD` format

```typescript
interface ColicPatternDocument {
  babyId: string;
  analysisDate: string;                 // "YYYY-MM-DD"

  // Daily breakdown (last N days)
  dailyAnalysis: Array<{
    date: string;
    totalCryingMinutes: number;
    colicCryingMinutes: number;
    totalEpisodes: number;
    colicEpisodes: number;
    longestEpisodeMinutes: number;
    peakHour: number;                   // 0–23, -1 if no events
    avgIntensity: number;
    meetsThreshold: boolean;            // >= 180 min (3 hours)
  }>;

  // Weekly summaries (ISO weeks, Mon–Sun)
  weeklySummaries: Array<{
    weekStart: string;                  // "YYYY-MM-DD" (Monday)
    daysOverThreshold: number;
    totalCryingMinutes: number;
    avgDailyCryingMinutes: number;
    meetsWessel: boolean;               // 3+ days over threshold
  }>;

  // Streaks
  currentStreak: number;                // Consecutive days meeting threshold
  longestStreak: number;
  wesselWeeksCount: number;             // Weeks meeting Wessel's criteria

  // Risk assessment
  riskLevel: "none" | "mild" | "moderate" | "severe";
  riskScore: number;                    // 0–100

  // Actionable guidance
  suggestions: string[];

  // Metadata
  analyzedAt: Timestamp;
  analyzedBy: string;                   // User UID or "scheduled"
}
```

### Risk Score Computation

```
score = 0
+ (recent_days_over_threshold_in_last_7 * 10)     // 0–70
+ min(current_streak * 5, 15)                       // 0–15
+ min(wessel_weeks_count * 10, 30)                  // 0–30
+ avg_crying_bonus (>4h: +10, >3h: +5)             // 0–10
= capped at 100
```

| Score | Risk Level |
|-------|------------|
| 0–14 | `none` |
| 15–39 | `mild` |
| 40–69 | `moderate` |
| 70–100 | `severe` |

## 4. Model Configuration

**Path**: `modelConfig/cryClassifier`
**Managed by**: Admin functions (`getModelConfig`, `updateModelConfig`)

```typescript
interface ModelConfigDocument {
  activeVersion: string;                // e.g. "heuristic-v1.0"
  backend: "heuristic" | "tfjs" | "vertex-ai";
  storagePath: string | null;           // TF.js model path in Storage
  vertexEndpointId: string | null;      // Vertex AI endpoint ID

  // A/B Testing (null when disabled)
  abTest: {
    challengerVersion: string;
    challengerBackend: "heuristic" | "tfjs" | "vertex-ai";
    challengerStoragePath: string | null;
    trafficPercent: number;             // 0–100 (% routed to challenger)
  } | null;

  // Audit
  lastUpdatedBy: string;                // Admin UID
  lastUpdatedAt: Timestamp;
}
```

## 5. Training Datasets

**Path**: `trainingDatasets/{version}`
**Created by**: `exportTrainingData` Cloud Function

```typescript
interface TrainingDatasetDocument {
  version: string;                      // Dataset version identifier
  totalEvents: number;
  byClassification: Record<string, number>;  // Count per cry type
  manifestPath: string;                 // Storage: training-data/{version}/manifest.jsonl
  exportedAt: Timestamp;
  exportedBy: string;                   // Admin UID
}
```

### JSONL Manifest Format

Each line in the manifest is a JSON object:

```json
{
  "eventId": "abc123",
  "babyId": "baby456",
  "classification": "hungry",
  "source": "parentCorrected",
  "confidence": 0.85,
  "audioFeaturesPath": "features/abc123.json",
  "sensorContext": { "heartRate": 130, "bodyTemp": 36.8 },
  "durationSeconds": 245
}
```

## 9. Denormalized Fields

Some data is denormalized for fast reads:

| Source | Target | Fields | Updated By |
|--------|--------|--------|------------|
| `cryEvents` classification | `babies/{id}.latestVitals` | Latest cry type and time | `onCryAudioUploaded` |
| `colicPatterns` risk | `babies/{id}.latestVitals` | `colicRiskLevel`, `colicRiskScore`, `colicAnalyzedAt` | `scheduledColicAnalysis` |
| User consent | `cryEvents` | `dataConsent` field on each event | Flutter app at event creation |
