## Executive Summary

This document defines the Firestore security rules and access control model for BabyTrack Monitor. The system uses three authorization levels: authenticated user, family member, and admin. Rules are defined in `firestore.rules` at the project root.

## 1. Authorization Levels

| Level | Requirement | Custom Claim | Use Case |
|-------|-------------|--------------|----------|
| **Authenticated** | Valid Firebase Auth token | None | General app access |
| **Family Member** | Authenticated + member of baby's family | None | Baby data access |
| **Owner** | Authenticated + `request.auth.uid == userId` | None | Own user document |
| **Admin** | Authenticated + admin custom claim | `admin: true` | Model config, training data, user management |

## 2. Helper Functions

Defined in `firestore.rules`:

```javascript
// Any authenticated user
function isAuthenticated() {
  return request.auth != null;
}

// User accessing their own document
function isOwner(userId) {
  return isAuthenticated() && request.auth.uid == userId;
}

// User with admin custom claim
function isAdmin() {
  return isAuthenticated() && request.auth.token.admin == true;
}

// User is a member of the family that owns a baby
function isFamilyMember(babyId) {
  let baby = get(/databases/$(database)/documents/babies/$(babyId));
  let familyId = baby.data.familyId;
  let family = get(/databases/$(database)/documents/families/$(familyId));
  return isAuthenticated() &&
    request.auth.uid in family.data.memberIds;
}
```

## 4. Collection Rules

### Users

```javascript
match /users/{userId} {
  allow read: if isOwner(userId) || isAdmin();
  allow write: if isOwner(userId);
}
```

Users can only read and write their own documents. Admins can read any user document (needed for admin management).

### Families

```javascript
match /families/{familyId} {
  allow read: if isAuthenticated() &&
    request.auth.uid in resource.data.memberIds;
  allow create: if isAuthenticated();
  allow update: if isAuthenticated() &&
    request.auth.uid in resource.data.memberIds;
  allow delete: if isAuthenticated() &&
    resource.data.ownerId == request.auth.uid;
}
```

Only family members can read/update. Only the owner can delete.

### Cry Events

```javascript
match /babies/{babyId}/cryEvents/{eventId} {
  allow read: if isAuthenticated();
  allow create: if isAuthenticated();
  allow update: if isAuthenticated();
  allow delete: if isAdmin();
}
```

Cry events cannot be deleted by regular users — only admins can delete (for data integrity). Updates are allowed for parent feedback and cloud classification writes.

### Data Delete Requests

```javascript
match /dataDeleteRequests/{requestId} {
  allow create: if isAuthenticated();
  allow read: if isAuthenticated() &&
    (resource.data.userId == request.auth.uid || isAdmin());
  allow update: if isAdmin();
  allow delete: if false;
}
```

Users can create deletion requests. Only the requesting user or admin can read. Only Cloud Functions (admin SDK) or admin users can update status. Deletion requests cannot be deleted (audit trail).

### Training Datasets

```javascript
match /trainingDatasets/{datasetId} {
  allow read: if isAdmin();
  allow write: if isAdmin();
}
```

Fully restricted to admin users. Contains ML training metadata.

## 5. Admin System

### Setting Admin Claims

Admin status is managed via Firebase Auth custom claims:

```typescript
// Cloud Function: setAdminClaim
admin.auth().setCustomUserClaims(targetUid, { admin: true });
```

**Constraints:**
- Only existing admins can grant/revoke admin status
- Admins cannot remove their own admin status (safety)
- All admin changes are logged in `adminAuditLog`

### Admin-Protected Operations

| Operation | Function | What It Does |
|-----------|----------|-------------|
| Model config read | `getModelConfig` | Read `modelConfig/cryClassifier` |
| Model config update | `updateModelConfig` | Modify backend, version, A/B test |
| Performance stats | `getModelPerformance` | Aggregate accuracy across babies |
| Grant/revoke admin | `setAdminClaim` | Modify custom claims |
| Export training data | `exportTrainingData` | Create ML training manifest |

## 6. GDPR Compliance

### Consent Tiers

| Tier | Stored | Purpose |
|------|--------|---------|
| `featuresOnly` (default) | Extracted audio features (~2KB) | Cloud classification, training |
| `fullAudio` | Features + raw audio (~20KB) | Higher quality training data |
| `none` | Nothing (event metadata only) | User opted out |

### Data Deletion Flow

```
User revokes consent in app
    → Creates dataDeleteRequest { status: "pending" }
    → onConsentRevoked trigger fires
    → Deletes audio features from Storage
    → Deletes raw audio from Storage
    → Clears ML fields from event docs (keeps event history)
    → Marks request as "completed"
```

### What Gets Deleted vs. Kept

| Data | Action | Reason |
|------|--------|--------|
| Audio features (Storage) | **Deleted** | Training data, user opted out |
| Raw audio (Storage) | **Deleted** | Sensitive audio data |
| Event metadata (Firestore) | **Kept** | Parent's cry log history |
| Classification results | **Cleared** | Derived from deleted features |
| Parent feedback | **Kept** | User's own input |

## 7. Production Hardening Notes

The current rules are functional but could be tightened for production:

### Recommended Improvements

| Area | Current | Recommended |
|------|---------|-------------|
| Baby access | `isAuthenticated()` | `isFamilyMember(babyId)` |
| Device access | `isAuthenticated()` | Family-scoped device check |
| Cry event create | `isAuthenticated()` | Family member of the baby |
| Cry event update | `isAuthenticated()` | Family member or Cloud Function |
| Rate limiting | None | Cloud Function rate limits |
| Field validation | None | `request.resource.data` checks |

### Example Tightened Rule

```javascript
// Production-ready cry events rule
match /babies/{babyId}/cryEvents/{eventId} {
  allow read: if isFamilyMember(babyId);
  allow create: if isFamilyMember(babyId) &&
    request.resource.data.babyId == babyId;
  allow update: if isFamilyMember(babyId) ||
    request.resource.data.classificationSource == 'cloud';
  allow delete: if isAdmin();
}
```
