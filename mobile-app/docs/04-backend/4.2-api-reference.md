## 1. Authentication

All callable functions require Firebase Authentication.

| Auth Level | Description | Custom Claim |
|-----------|-------------|--------------|
| **Authenticated** | Any signed-in user | None |
| **Admin** | Admin-only functions | `admin: true` |

**Flutter usage:**

```dart
final functions = FirebaseFunctions.instance;
final result = await functions.httpsCallable('functionName').call(data);
```

## 2. Cry Classification

### `classifyCry`

Classify a cry event on demand using the cloud ML pipeline.

**Auth**: Authenticated
**Source**: `cryClassification.ts`

**Input:**

```typescript
{
  babyId: string;        // Required — baby document ID
  eventId: string;       // Required — cry event document ID
}
```

**Output:**

```typescript
{
  classification: string;     // "hungry" | "tired" | "pain" | "colic" | "gassy" | "discomfort" | "attention" | "overstimulated" | "unknown"
  confidence: number;         // 0.0–1.0
  probabilities: Record<string, number>;  // Per-class probabilities
  modelVersion: string;       // e.g. "heuristic-v1.0"
  processingTimeMs: number;
}
```

**Errors:**

| Code | Condition |
|------|-----------|
| `unauthenticated` | No Firebase auth token |
| `invalid-argument` | Missing `babyId` or `eventId` |
| `not-found` | Event or baby document not found |
| `internal` | Classification engine failure |

## 3. Colic Pattern Detection

### `detectColicPatterns`

Analyze cry event history for a baby using modified Wessel's criteria.

**Auth**: Authenticated
**Source**: `colicPatternDetector.ts`

**Input:**

```typescript
{
  babyId: string;            // Required — baby document ID
  lookbackDays?: number;     // Optional — analysis window (default: 21)
}
```

**Output:**

```typescript
{
  babyId: string;
  analysisDate: string;           // "YYYY-MM-DD"
  dailyAnalysis: ColicDayAnalysis[];
  weeklySummaries: ColicWeekSummary[];
  currentStreak: number;          // Consecutive days meeting threshold
  longestStreak: number;
  wesselWeeksCount: number;       // Weeks meeting full Wessel's criteria
  riskLevel: "none" | "mild" | "moderate" | "severe";
  riskScore: number;              // 0–100
  suggestions: string[];
}
```

**ColicDayAnalysis:**

```typescript
{
  date: string;                   // "YYYY-MM-DD"
  totalCryingMinutes: number;
  colicCryingMinutes: number;
  totalEpisodes: number;
  colicEpisodes: number;
  longestEpisodeMinutes: number;
  peakHour: number;               // 0–23, -1 if no events
  avgIntensity: number;           // 0.0–1.0
  meetsThreshold: boolean;        // true if >= 180 min (3 hours)
}
```

**ColicWeekSummary:**

```typescript
{
  weekStart: string;              // "YYYY-MM-DD" (Monday)
  daysOverThreshold: number;
  totalCryingMinutes: number;
  avgDailyCryingMinutes: number;
  meetsWessel: boolean;           // true if 3+ days over threshold
}
```

**Side Effects:**
- Stores result in `babies/{babyId}/colicPatterns/{analysisDate}`

**Errors:**

| Code | Condition |
|------|-----------|
| `unauthenticated` | No Firebase auth token |
| `invalid-argument` | Missing `babyId` |
| `internal` | Analysis engine failure |

## 4. Training Data Export

### `exportTrainingData`

Export labeled cry events as a JSONL manifest for ML training.

**Auth**: Admin
**Source**: `trainingExport.ts`

**Input:**

```typescript
{
  version: string;           // Required — dataset version identifier (e.g. "v1.0")
  minConfidence?: number;    // Optional — minimum confidence threshold
}
```

**Output:**

```typescript
{
  version: string;
  totalEvents: number;
  byClassification: Record<string, number>;   // Count per cry type
  manifestPath: string;                        // Storage path to JSONL file
}
```

**Side Effects:**
- Writes JSONL manifest to `training-data/{version}/manifest.jsonl` in Firebase Storage
- Records metadata in `trainingDatasets/{version}` Firestore collection
- Marks exported events with `exportedToTraining: true`

**Errors:**

| Code | Condition |
|------|-----------|
| `unauthenticated` | No Firebase auth token |
| `permission-denied` | User lacks `admin` custom claim |

## 5. Model Configuration (Admin)

### `getModelConfig`

Read the current cry classifier model configuration.

**Auth**: Admin
**Source**: `adminFunctions.ts`

**Input:** None (empty `{}`)

**Output:**

```typescript
{
  activeVersion: string;         // e.g. "heuristic-v1.0"
  backend: string;               // "heuristic" | "tfjs" | "vertex-ai"
  storagePath?: string;          // TF.js model Storage path
  vertexEndpointId?: string;     // Vertex AI endpoint ID
  abTest?: {
    challengerVersion: string;
    challengerBackend: string;
    challengerStoragePath?: string;
    trafficPercent: number;      // 0–100
  } | null;
  lastUpdatedBy?: string;
  lastUpdatedAt?: Timestamp;
}
```

**Default** (when no config exists):

```typescript
{
  activeVersion: "heuristic-v1.0",
  backend: "heuristic",
  abTest: null
}
```

---

### `updateModelConfig`

Update the cry classifier model configuration. Supports partial updates.

**Auth**: Admin
**Source**: `adminFunctions.ts`

**Input:**

```typescript
{
  activeVersion?: string;
  backend?: "heuristic" | "tfjs" | "vertex-ai";
  storagePath?: string;
  vertexEndpointId?: string;
  abTest?: {
    challengerVersion: string;        // Required if abTest provided
    challengerBackend: string;        // Required if abTest provided
    challengerStoragePath?: string;
    trafficPercent: number;           // Required, 0–100
  } | null;                           // null disables A/B testing
}
```

**Output:** Full updated config (same shape as `getModelConfig` output).

**Side Effects:**
- Updates `modelConfig/cryClassifier` in Firestore
- Creates audit log entry in `adminAuditLog`

**Errors:**

| Code | Condition |
|------|-----------|
| `unauthenticated` | No Firebase auth token |
| `permission-denied` | User lacks `admin` custom claim |
| `invalid-argument` | Invalid backend value, missing A/B test fields, trafficPercent out of range, or no valid fields provided |

## 6. Model Performance (Admin)

### `getModelPerformance`

Aggregate classification accuracy stats across babies.

**Auth**: Admin
**Source**: `adminFunctions.ts`

**Input:**

```typescript
{
  babyIds?: string[];    // Optional — filter to specific babies (all if omitted)
  days?: number;         // Optional — lookback window in days (default: 30)
}
```

**Output:**

```typescript
{
  totalClassified: number;
  totalWithGroundTruth: number;
  cloudAccuracy: number;                     // 0.0–1.0
  edgeAccuracy: number;                      // 0.0–1.0
  classificationBreakdown: Record<string, number>;  // Count per cry type
  avgProcessingTimeMs: number;
  modelVersionBreakdown: Record<string, number>;    // Count per model version
  abTestStats?: {                            // Present only if A/B test active
    primaryCount: number;
    challengerCount: number;
    primaryAccuracy: number;
    challengerAccuracy: number;
  };
}
```

**Ground Truth Logic:**
Priority: `parentCorrectedType` > confirmed `cloudClassification` (when `parentConfirmed: true`)

## 7. Admin User Management

### `setAdminClaim`

Grant or revoke admin status on a Firebase Auth user.

**Auth**: Admin
**Source**: `adminFunctions.ts`

**Input:**

```typescript
{
  targetUid: string;     // Required — user to modify
  isAdmin: boolean;      // Required — true to grant, false to revoke
}
```

**Output:**

```typescript
{
  success: true;
  targetUid: string;
  isAdmin: boolean;
}
```

**Side Effects:**
- Sets custom claim `{ admin: isAdmin }` on target user
- Creates audit log entry in `adminAuditLog`

**Errors:**

| Code | Condition |
|------|-----------|
| `unauthenticated` | No Firebase auth token |
| `permission-denied` | Caller lacks `admin` claim |
| `invalid-argument` | Missing `targetUid` or `isAdmin` not boolean |
| `failed-precondition` | Cannot remove own admin status |

## 8. Error Codes

All callable functions use standard `functions.https.HttpsError` codes:

| Code | HTTP | Meaning |
|------|------|---------|
| `unauthenticated` | 401 | No valid auth token |
| `permission-denied` | 403 | Missing required role (admin) |
| `invalid-argument` | 400 | Missing or invalid input parameters |
| `not-found` | 404 | Referenced document doesn't exist |
| `failed-precondition` | 400 | Operation not allowed in current state |
| `internal` | 500 | Server-side processing error |
