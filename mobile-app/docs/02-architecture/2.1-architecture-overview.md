## Executive Summary

The AnvayaPod BabyTrack platform is a distributed system consisting of IoT devices, mobile applications, and cloud services. This document provides a high-level view of how all components work together.

## Component Summary

## Domain-Driven Design

The system is organized into bounded contexts:

### Core Domain (Build In-House)
| Context | Purpose | Key Entities |
|---------|---------|--------------|
| **Baby Monitoring** | Real-time health tracking | Baby, Vitals, SleepSession |
| **Health Insights** | AI predictions, anomalies | Prediction, Anomaly, Benchmark |
| **Memory Keeper** | Photos and memories | Photo, Album, BabyBook |
| **Growth Journey** | Milestones and development | Milestone, Achievement |

### Supporting Domain
| Context | Purpose | Key Entities |
|---------|---------|--------------|
| **Family Circle** | Multi-user access | Family, Member, Permission |
| **Coaching** | Tips and challenges | Tip, Challenge, Streak |
| **Device Management** | IoT device lifecycle | Device, Command, Firmware |
| **Notifications** | Alert delivery | Notification, Preference |

### Generic Domain (Use SaaS)
| Context | Implementation |
|---------|----------------|
| **Identity** | Firebase Auth |
| **Billing** | RevenueCat / Stripe |
| **Support** | Intercom / Zendesk |
| **Content** | CMS (future) |

## Scalability Strategy

### Current Scale (0-10K Users)
- Single Firestore instance
- Firebase Functions (auto-scaling)
- Standard Firebase quotas

### Growth Scale (10K-100K Users)
- Firestore with regional failover
- Cloud Run for CPU-intensive tasks
- Redis cache layer
- BigQuery for analytics offload

### Enterprise Scale (100K+ Users)
- Multi-region deployment
- Dedicated IoT Core instance
- Sharded data by region
- Custom ML model serving

## Key Architectural Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Database | Firestore | Real-time sync, offline support, scaling |
| State Management | Provider | Simple, Flutter-native, sufficient for app |
| IoT Protocol | MQTT over WiFi | Low latency, efficient for continuous data |
| Provisioning | BLE | No internet needed during setup |
| ML Inference | Cloud (Vertex AI) | Accuracy over latency for predictions |
| Photo AI | Vision API | Best-in-class face/mood detection |
| Push Notifications | FCM | Cross-platform, Firebase integration |
