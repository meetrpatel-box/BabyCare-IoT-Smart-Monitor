## 1. Overview

### 1.1 Testing Challenges

| Challenge | Solution |
|-----------|----------|
| **No Physical Device** | Device Simulator Web App |
| **Firebase Costs** | Firebase Emulator Suite (local) |
| **Sensor Data Testing** | Mock Data Generators |
| **End-to-End Flows** | Automated E2E Tests |
| **Cloud Functions** | Local Function Emulation |
| **Real-time Updates** | WebSocket Test Harness |

### 1.2 Testing Pyramid

```
                    ▲
                   ╱ ╲
                  ╱ E2E╲              5% - End-to-End Tests
                 ╱───────╲             (Full user flows)
                ╱         ╲
               ╱Integration╲          15% - Integration Tests
              ╱─────────────╲         (Firebase, APIs, Services)
             ╱               ╲
            ╱  Unit Tests     ╲      80% - Unit Tests
           ╱___________________╲     (Models, Services, Widgets)
```

## 2. Testing Strategy

### 2.1 Three-Tier Testing Approach

#### **Tier 1: Local Development (No Internet)**
- Unit tests with mocks
- Widget tests with test fixtures
- Offline-first validation
- No Firebase dependency

#### **Tier 2: Firebase Emulator (Local Network)**
- Integration tests with Firebase emulators
- Cloud Functions local execution
- Firestore rules testing
- Real-time updates testing
- **Cost**: $0 (completely free)

#### **Tier 3: Staging Environment (Cloud)**
- End-to-end tests with real Firebase
- Device simulator pushing to staging project
- Performance testing
- Load testing
- **Cost**: Minimal (free tier usually sufficient)

### 2.2 Test Coverage Goals

| Layer | Target Coverage | Priority |
|-------|----------------|----------|
| Models | 95%+ | Critical |
| Services | 90%+ | Critical |
| Providers | 85%+ | High |
| Widgets | 80%+ | High |
| Screens | 70%+ | Medium |
| Cloud Functions | 90%+ | Critical |
| E2E Flows | Key flows only | Medium |

### 3.3 Connect Flutter App to Emulators

**File**: `lib/config/firebase_config.dart`

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:cloud_firestore/cloud_firestore.dart';
import 'package:firebase_auth/firebase_auth.dart';
import 'package:firebase_storage/firebase_storage.dart';
import 'package:cloud_functions/cloud_functions.dart';

class FirebaseConfig {
  static const bool useEmulator = bool.fromEnvironment('USE_EMULATOR', defaultValue: false);
  
  static Future<void> initialize() async {
    await Firebase.initializeApp();
    
    if (useEmulator) {
      _connectToEmulators();
    }
  }
  
  static void _connectToEmulators() {
    print('🔧 Connecting to Firebase Emulators...');
    
    // Firestore
    FirebaseFirestore.instance.useFirestoreEmulator('localhost', 8080);
    
    // Auth
    FirebaseAuth.instance.useAuthEmulator('localhost', 9099);
    
    // Storage
    FirebaseStorage.instance.useStorageEmulator('localhost', 9199);
    
    // Functions
    FirebaseFunctions.instance.useFunctionsEmulator('localhost', 5001);
    
    print('✅ Connected to emulators');
  }
}
```

**Run with emulators**:
```bash
flutter run --dart-define=USE_EMULATOR=true
flutter test --dart-define=USE_EMULATOR=true
```

### 4.2 Device Simulator Implementation

**File**: `test/device_simulator/lib/main.dart`

```dart
import 'package:flutter/material.dart';
import 'package:cloud_firestore/cloud_firestore.dart';
import 'dart:async';
import 'dart:math';

void main() {
  runApp(DeviceSimulatorApp());
}

class DeviceSimulatorApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'AnvayaPod Simulator',
      theme: ThemeData(
        primarySwatch: Colors.blue,
        brightness: Brightness.dark,
      ),
      home: DeviceSimulatorScreen(),
    );
  }
}

class DeviceSimulatorScreen extends StatefulWidget {
  @override
  _DeviceSimulatorScreenState createState() => _DeviceSimulatorScreenState();
}

class _DeviceSimulatorScreenState extends State<DeviceSimulatorScreen> {
  final FirebaseFirestore _firestore = FirebaseFirestore.instance;
  final Random _random = Random();
  
  String _selectedBabyId = 'test-baby-1';
  String _deviceId = 'simulator-001';
  bool _isStreaming = false;
  Timer? _streamTimer;
  
  // Current sensor values
  double _heartRate = 140.0;
  double _respiratoryRate = 40.0;
  double _bodyTemp = 37.0;
  double _roomTemp = 22.0;
  double _humidity = 50.0;
  bool _movementDetected = false;
  
  // Streaming settings
  int _streamIntervalSeconds = 5;
  bool _addRealisticVariance = true;

  @override
  void dispose() {
    _streamTimer?.cancel();
    super.dispose();
  }

  void _startStreaming() {
    setState(() => _isStreaming = true);
    
    _streamTimer = Timer.periodic(
      Duration(seconds: _streamIntervalSeconds),
      (timer) => _publishSensorData(),
    );
  }

  void _stopStreaming() {
    setState(() => _isStreaming = false);
    _streamTimer?.cancel();
  }

  void _publishSensorData() async {
    // Add realistic variance if enabled
    if (_addRealisticVariance) {
      _heartRate += _random.nextDouble() * 4 - 2; // ±2 BPM
      _heartRate = _heartRate.clamp(120.0, 180.0);
      
      _respiratoryRate += _random.nextDouble() * 2 - 1; // ±1 BPM
      _respiratoryRate = _respiratoryRate.clamp(30.0, 60.0);
      
      _bodyTemp += _random.nextDouble() * 0.2 - 0.1; // ±0.1°C
      _bodyTemp = _bodyTemp.clamp(36.0, 38.0);
      
      _roomTemp += _random.nextDouble() * 0.4 - 0.2;
      _roomTemp = _roomTemp.clamp(18.0, 28.0);
      
      _humidity += _random.nextDouble() * 2 - 1;
      _humidity = _humidity.clamp(30.0, 70.0);
    }

    final vitalSigns = {
      'deviceId': _deviceId,
      'babyId': _selectedBabyId,
      'timestamp': FieldValue.serverTimestamp(),
      'heartRate': _heartRate.roundToDouble(),
      'respiratoryRate': _respiratoryRate.roundToDouble(),
      'bodyTemperature': double.parse(_bodyTemp.toStringAsFixed(1)),
      'roomTemperature': double.parse(_roomTemp.toStringAsFixed(1)),
      'humidity': _humidity.roundToDouble(),
      'movementDetected': _movementDetected,
      'source': 'simulator',
    };

    try {
      await _firestore
          .collection('vital_signs')
          .add(vitalSigns);
      
      print('✅ Published: HR=${_heartRate.round()}, RR=${_respiratoryRate.round()}, Temp=${_bodyTemp.toStringAsFixed(1)}°C');
      
      setState(() {}); // Update UI
    } catch (e) {
      print('❌ Error publishing data: $e');
    }
  }

  void _triggerMilestoneEvent(String eventType) async {
    // Simulate milestone trigger events
    final event = {
      'deviceId': _deviceId,
      'babyId': _selectedBabyId,
      'eventType': eventType,
      'timestamp': FieldValue.serverTimestamp(),
      'source': 'simulator',
    };

    await _firestore.collection('device_events').add(event);
    
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Triggered: $eventType')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('AnvayaPod Simulator'),
        actions: [
          IconButton(
            icon: Icon(_isStreaming ? Icons.stop : Icons.play_arrow),
            onPressed: _isStreaming ? _stopStreaming : _startStreaming,
          ),
        ],
      ),
      body: ListView(
        padding: EdgeInsets.all(16),
        children: [
          // Device Info
          Card(
            child: ListTile(
              leading: Icon(Icons.sensors, color: Colors.blue),
              title: Text('Device ID: $_deviceId'),
              subtitle: Text('Baby ID: $_selectedBabyId'),
              trailing: Icon(
                _isStreaming ? Icons.circle : Icons.circle_outlined,
                color: _isStreaming ? Colors.green : Colors.grey,
              ),
            ),
          ),
          
          SizedBox(height: 16),
          
          // Heart Rate
          _buildSensorControl(
            'Heart Rate',
            _heartRate,
            'BPM',
            Icons.favorite,
            Colors.red,
            120.0,
            180.0,
            (value) => setState(() => _heartRate = value),
          ),
          
          // Respiratory Rate
          _buildSensorControl(
            'Respiratory Rate',
            _respiratoryRate,
            'BPM',
            Icons.air,
            Colors.blue,
            30.0,
            60.0,
            (value) => setState(() => _respiratoryRate = value),
          ),
          
          // Body Temperature
          _buildSensorControl(
            'Body Temperature',
            _bodyTemp,
            '°C',
            Icons.thermostat,
            Colors.orange,
            36.0,
            38.0,
            (value) => setState(() => _bodyTemp = value),
          ),
          
          // Room Temperature
          _buildSensorControl(
            'Room Temperature',
            _roomTemp,
            '°C',
            Icons.home,
            Colors.teal,
            18.0,
            28.0,
            (value) => setState(() => _roomTemp = value),
          ),
          
          // Humidity
          _buildSensorControl(
            'Humidity',
            _humidity,
            '%',
            Icons.water_drop,
            Colors.cyan,
            30.0,
            70.0,
            (value) => setState(() => _humidity = value),
          ),
          
          SizedBox(height: 16),
          
          // Movement Detection
          SwitchListTile(
            title: Text('Movement Detected'),
            subtitle: Text('Simulate baby movement'),
            value: _movementDetected,
            onChanged: (value) => setState(() => _movementDetected = value),
            secondary: Icon(Icons.directions_walk),
          ),
          
          SizedBox(height: 16),
          
          // Stream Settings
          Card(
            child: Padding(
              padding: EdgeInsets.all(16),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text('Stream Settings', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
                  SizedBox(height: 8),
                  Text('Interval: $_streamIntervalSeconds seconds'),
                  Slider(
                    value: _streamIntervalSeconds.toDouble(),
                    min: 1,
                    max: 60,
                    divisions: 59,
                    label: '$_streamIntervalSeconds sec',
                    onChanged: (value) => setState(() => _streamIntervalSeconds = value.toInt()),
                  ),
                  SwitchListTile(
                    title: Text('Realistic Variance'),
                    subtitle: Text('Add natural sensor fluctuations'),
                    value: _addRealisticVariance,
                    onChanged: (value) => setState(() => _addRealisticVariance = value),
                  ),
                ],
              ),
            ),
          ),
          
          SizedBox(height: 16),
          
          // Milestone Triggers
          Text('Milestone Event Triggers', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
          SizedBox(height: 8),
          Wrap(
            spacing: 8,
            runSpacing: 8,
            children: [
              ElevatedButton.icon(
                icon: Icon(Icons.bedtime),
                label: Text('Long Sleep (6h)'),
                onPressed: () => _triggerMilestoneEvent('long_sleep_6h'),
              ),
              ElevatedButton.icon(
                icon: Icon(Icons.restaurant),
                label: Text('Solid Food'),
                onPressed: () => _triggerMilestoneEvent('solid_food'),
              ),
              ElevatedButton.icon(
                icon: Icon(Icons.child_care),
                label: Text('Rolling Over'),
                onPressed: () => _triggerMilestoneEvent('rolling_over'),
              ),
            ],
          ),
          
          SizedBox(height: 16),
          
          // Quick Actions
          ElevatedButton.icon(
            icon: Icon(Icons.publish),
            label: Text('Publish Single Reading'),
            onPressed: _publishSensorData,
            style: ElevatedButton.styleFrom(
              padding: EdgeInsets.symmetric(vertical: 16),
            ),
          ),
        ],
      ),
    );
  }

  Widget _buildSensorControl(
    String label,
    double value,
    String unit,
    IconData icon,
    Color color,
    double min,
    double max,
    ValueChanged<double> onChanged,
  ) {
    return Card(
      child: Padding(
        padding: EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Row(
              children: [
                Icon(icon, color: color),
                SizedBox(width: 8),
                Text(label, style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
                Spacer(),
                Text(
                  '${value.toStringAsFixed(1)} $unit',
                  style: TextStyle(fontSize: 20, color: color),
                ),
              ],
            ),
            Slider(
              value: value,
              min: min,
              max: max,
              divisions: ((max - min) * 10).toInt(),
              label: '${value.toStringAsFixed(1)} $unit',
              onChanged: onChanged,
              activeColor: color,
            ),
          ],
        ),
      ),
    );
  }
}
```

### 7.1 Setup Checklist

- [ ] Install Firebase CLI: `npm install -g firebase-tools`
- [ ] Initialize Firebase emulators: `firebase init emulators`
- [ ] Create device simulator Flutter app
- [ ] Add mock data generators
- [ ] Set up CI/CD integration tests
- [ ] Create test data seed files

### 7.2 Daily Development Workflow

```bash
# 1. Start Firebase emulators
firebase emulators:start --import=./test-data

# 2. In another terminal, run device simulator
cd test/device_simulator
flutter run -d chrome --dart-define=USE_EMULATOR=true

# 3. In another terminal, run main app
cd baby_track_flutter
flutter run -d chrome --dart-define=USE_EMULATOR=true

# 4. Run tests
flutter test --dart-define=USE_EMULATOR=true
```

### 7.3 CI/CD Pipeline

**File**: `.github/workflows/test.yml`

```yaml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Flutter
        uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.16.0'
      
      - name: Install dependencies
        run: flutter pub get
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      
      - name: Install Firebase CLI
        run: npm install -g firebase-tools
      
      - name: Start Firebase Emulators
        run: |
          firebase emulators:start --only firestore,auth &
          sleep 10
      
      - name: Run unit tests
        run: flutter test --dart-define=USE_EMULATOR=true
      
      - name: Run integration tests
        run: flutter test integration_test --dart-define=USE_EMULATOR=true
```
